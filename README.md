# Audiochan Archive

Репозиторий: https://github.com/ctrlaltkebab/audio4aner. Рабочая папка на этом компьютере: `G:\GitHub\audio4aner`.

Локальная библиотека аудио, сценариев и авторов Audiochan. Внешние ссылки не заменяют сохранённые файлы: аудио скачивается на диск и воспроизводится локально.

## Запуск в Windows

Дважды щёлкните **`audiochan.bat`**. Откроется библиотека на **http://127.0.0.1:8765**. Пока пользуетесь приложением, оставляйте окно программы открытым. Остановка — Ctrl+C в его окне.

Python, библиотеки и окружение находятся внутри проекта: `.python/`, `.venv/`, `bin/`. Системные пакеты Python не устанавливаются и не обновляются. Если `bin/uv.exe` отсутствует после клонирования, запуск скачает зафиксированный официальный выпуск `uv` и проверит SHA-256 архива. Затем подготовит Python и виртуальную среду `.venv` с зависимостями из `uv.lock`. Для первого восстановления отсутствующего окружения нужен интернет. Обычный просмотр готовой библиотеки не обращается к Audiochan.

При переносе на другой диск или компьютер копируйте папку целиком. Виртуальная среда не является форматом резервной копии: её можно пересоздать запуском программы. При несовместимости старой `.venv` закройте программу, переименуйте `.venv` в `.venv-old` и запустите ещё раз. Данные в `library/` и `data/` от этого не меняются.

В Linux/macOS есть `audiochan.sh`; нужен менеджер `uv` с официального сайта https://docs.astral.sh/uv/. Окружение также создаётся внутри проекта. На этих ОС запуск пока не проверялся.

## Как добавлять

1. В userscript нажимайте плюс на страницах `/a/…`, `/s/…` или `/u/…`. Поддерживаются также NumPad `+` и NumPad `−` в версии 1.2.
2. В панели userscript нажмите **Скачать TXT**.
3. В архиваторе откройте **Добавить ссылки → Выбрать TXT** или вставьте ссылки вручную.
4. Нажмите **Сохранить в библиотеку**.

Флажок «После текста скачать аудио и иллюстрации» включён по умолчанию. Если снять его, сохранятся только карточки и текст сценариев; медиа можно докачать в разделе «Загрузки» или из карточки. Повторяющиеся URL пропускаются, параметры комментариев отбрасываются.

Сначала обрабатывается текст всех ожидающих карточек, затем — их файлы. Если новая ссылка приходит во время скачивания, её текст будет обработан после текущей работы. Очередь сохраняется; после перезапуска прерванная задача продолжается с незавершённого этапа. Частичный файл скачивается заново, а уже успешно сохранённые файлы пропускаются.

Отметка автора сохраняет его публичный профиль. Все его произведения автоматически не загружаются. Участники сохранённых работ тоже получают локальные страницы, с отдельными ролями голоса, текста, SFX и другими. Если в подписи указано только имя без аккаунта, это отмечено; совпадающие имена без профиля группируются как неподтверждённая подпись, а не установленная личность.

Веб-приложение имеет поиск по названию/описанию/сценарию/участникам, фильтр тега, отрицательный фильтр тега и фильтр состояния. Исходные категории тегов сохранены и оформлены разными цветами. Это свойства карточки; настройки подписок и блокировок из аккаунта сайта пока не импортируются.

Плеер использует локальные файлы, умеет перемотку, скорость и запоминает позицию отдельно для каждой дорожки. Можно открыть файл напрямую из карточки или из Проводника. **Альтернативные версии сохраняются все**, с исходными названиями (например, `With SFX` и `No added sfx`). Если основная дорожка повторяется в списке вариантов, физический файл скачивается один раз. Ошибка одной версии не стирает остальные; повтор загружает недостающую дорожку. Названия всех ожидаемых вариантов сохраняются уже вместе с текстом, до скачивания аудио.

## Что хранится на диске

```text
library/
  index.html                      автономный общий индекс
  audio/<slug> - <название>/
    source.json                   исходная карточка API
    entry.json                    данные архива, локальные пути, SHA-256
    README.md                     обычный читаемый текст
    page.html                     автономная страница
    media/*.m4a                    обычные аудиофайлы и иллюстрации
  script/<slug> - <название>/      сценарии в тех же форматах
  author/<id> - <имя>/             профили и страницы участников
data/
  queue.json                      список задач и ошибки
  user.json                       позиции воспроизведения
  index.sqlite                    пересоздаваемый поисковый индекс
private/                          служебные данные, не раздаются веб-сервером
var/                              временные файлы и проверочные материалы
```

Для резервной копии важны **`library/` и `data/`**. JSON, Markdown и медиа доступны без приложения. `library/index.html` и отдельные `page.html` можно открыть двойным щелчком без Python и сервера. Ссылки на оригинальный сайт и внешние профили требуют интернета только при переходе по ним.

GitHub хранит код, документацию и userscript. Библиотека, все пользовательские данные, SQLite и другие базы, очередь, позиции, `private/`, ключи, файлы `.env`, окружения и кэши исключены через `.gitignore`. **GitHub не является резервной копией вашей библиотеки.** Секреты храните в `private/` или `.env`, а не в исходном коде; шаблоны `.env.example` допускаются без реальных значений.

Кнопка **Восстановить индекс** в «Загрузках» пересобирает SQLite и HTML из `entry.json`, не меняя сохранённые исходные карточки, файлы и позиции. Каждый `entry.json` — основа восстановления собственной карточки; `source.json` дополнительно сохраняет оригинальный ответ сайта.

При ошибке сайта старая успешная карточка и её медиа не удаляются. Ошибка получения файла не превращается в файл `.m4a`: до проверки HTTP, типа, размера, контейнера и длительности используется `.part`. В метаданных хранится контрольная сумма SHA-256.

## Команды

Из папки проекта:

```powershell
.\audiochan.bat serve
.\audiochan.bat import C:\путь\audiochan-urls.txt
.\audiochan.bat import C:\путь\audiochan-urls.txt --text-only
.\audiochan.bat download
.\audiochan.bat rebuild
.\audiochan.bat verify
```

`download` запускает докачивание/повтор очереди, `rebuild` восстанавливает индекс и HTML, `verify` проверяет размеры и SHA-256 всех сохранённых вложений. Перед отдельной командой закройте работающий сервер: два процесса не могут одновременно записывать один архив.

Разработка и проверки: `bin\uv.exe sync --frozen`, затем `.venv\Scripts\python.exe -m pytest`. Повседневный запуск устанавливает только рабочие зависимости, без тестовых пакетов.

## Проверено и ограничения первой версии

Проверено 23 октября 2026:

- Импорт трёх ваших примеров: аудио, сценарий, автор; создано четыре страницы участников.
- Полный локальный M4A: 19 200 807 байт, AAC, 604,9 секунды; полное декодирование FFmpeg без ошибок.
- Воспроизведение и перемотка в браузере с локального адреса, сохранение позиции.
- Сохранение сценария, исходных категорий тегов, ролей участников и изображений.
- Автоматические проверки: перенос данных и восстановление индекса, очередь/ошибки/перезапуск, постраничная большая очередь, безопасный разбор текста, отклонение HTML вместо аудио, Range/локальные пути/проверка запросов, блокировка второго экземпляра, альтернативные дорожки и повтор отдельной неудачной версии.

Загрузка рассчитана на доступные публичные карточки. Вход в аккаунт и перенос его авторизационного сеанса ещё не реализованы: при требовании входа/проверки задача остаётся с ошибкой, сохранённые данные доступны. Альтернативные дорожки проверяются на релизе `Fi893kZwakAmbUxhqI`; другие схемы многовариантных публикаций могут потребовать дополнений. Интерактивы, история сайта и плейлисты отложены.

Автоматическое получение оригинального WAV вместо версии плеера не заявлено: сохраняется реально доступная версия воспроизведения, с проверенным контейнером, независимо от расширения исходного имени.

Облачное развёртывание и доступ по сети не настроены. Сервер слушает только этот компьютер. Архитектура и обычные файлы позволяют перенести его на свой сервер позже, но для публикации потребуется отдельная настройка доступа и HTTPS.

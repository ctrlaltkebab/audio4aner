# Audiochan — список для будущего архиватора

Версия 1.2.0: **плюс на нумпаде** добавляет текущую страницу, **минус на нумпаде** удаляет. Работает только на `/a/…`, `/s/…` и `/u/…`. Повторный плюс не удаляет запись, повторный минус не добавляет её. При вводе в текстовые поля и редакторы, а также с Ctrl/Alt/Shift/Win горячие клавиши не перехватываются. Обычные плюс и минус в основном ряду клавиатуры не затрагиваются.

Версия 1.1.1: элементы скрипта размещены поверх страницы, вне `body`, и не занимают места в её сетке. Клики за пределами кнопок и открытой панели проходят к сайту.

1. В Tampermonkey или Violentmonkey создайте новый userscript.
2. Замените шаблон полным содержимым `audiochan-save-list.user.js`, сохраните.
3. Обновите Audiochan. На страницах аудио `/a/…`, сценариев `/s/…` и авторов `/u/…` справа внизу появится круглая кнопка **+**.

Если версия 1.0 уже установлена, замените код **того же скрипта** и сохраните. Название, namespace и ключи хранилища сохранены; прежние отметки аудио останутся.

Отметка автора означает «этот автор интересен». Она не ставит все его произведения на скачивание. В TXT все три типа ссылок идут общим списком: будущий архиватор различит их по `/a/`, `/s/`, `/u/`. В хранилище у новых записей дополнительно сохраняется тип `audio`, `script` или `author`.

**+** сохраняет URL. После добавления появляется **−**, который удаляет URL из списка. Параметры комментариев, поиска и фрагменты URL отбрасываются: одна работа учитывается один раз. Переходы внутри сайта без перезагрузки поддерживаются; кнопка обновляется в течение 1,5 секунды.

Рядом есть **Список · N**. Он доступен и на других страницах Audiochan:

- **Скачать TXT** — получить обычный UTF-8-файл, одна ссылка на строку. Это готовая очередь для будущего архиватора.
- **Копировать** — скопировать сохранённый список.
- **Добавить из поля** — вставить прежний список/содержимое TXT и объединить с текущим без повторов. Отсутствующие в поле ссылки при этом не удаляются.

Список хранится в постоянном хранилище самого userscript, предоставляемом менеджером расширения, отдельно от localStorage Audiochan. Закрытие страницы, выход с сайта и обычное обновление страницы его не стирают. Все вкладки в одном профиле используют один список; каждая ссылка хранится отдельно, поэтому одновременное добавление разных работ не перезаписывает другие ссылки.

Хранилище не синхронизируется с другим браузером или компьютером автоматически. Удаление расширения, профиля или самого скрипта вместе с его данными может удалить список. Поэтому периодически скачивайте TXT. При обновлении заменяйте код существующего скрипта, сохраняя его имя и namespace.

Скрипт не скачивает аудио, не обращается к локальному серверу и не отправляет список на сторонние сервисы. Архиватор для сбора ссылок не нужен.

В этой версии проверены синтаксис и работа на локальной тестовой странице с имитацией API менеджера userscript. Установка в ваш менеджер и работа на живом Audiochan требуют отдельной проверки.
